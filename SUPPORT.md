# Support

This repository is **unofficial**: an independent Windows x64 packaging
project for the upstream [pglogical](https://github.com/2ndQuadrant/pglogical)
extension. There is no commercial support and no SLA — issues and pull
requests are handled on a best-effort basis.

## Ask here

For problems with this project's packages and pipeline:

* Windows packaging / install issues (ZIP layout, extraction, missing files).
* Package missing files or incorrect release metadata.
* Windows-specific build failures.
* Workflow / release pipeline problems.

Open an issue using the
[issue templates](https://github.com/semihkiroglu/pglogical-windows/issues/new/choose).
For security-related reports, follow [SECURITY.md](SECURITY.md).

## Ask upstream

For problems with pglogical itself:

* pglogical SQL/API semantics.
* Generic logical replication behavior.
* Bugs reproducible with upstream pglogical on officially supported platforms
  and unrelated to this Windows packaging.

Open an issue at
[https://github.com/2ndQuadrant/pglogical/issues](https://github.com/2ndQuadrant/pglogical/issues).
